# Industrial BI Dashboard

Projeto estático em HTML5, CSS3, JavaScript e Chart.js.

## Como abrir no Visual Studio Code

1. Extraia o arquivo ZIP.
2. Abra a pasta `Industrial-BI-Dashboard` no Visual Studio Code.
3. Abra `index.html` no navegador ou utilize a extensão Live Server.
4. Entre com:
   - Usuário: `admin`
   - Senha: `bi2026`

A conexão com a internet é necessária para carregar o Chart.js e as fontes utilizadas no projeto.
